## 🌟 What is BizFlow AI?

BizFlow AI is a **Laravel-powered business automation platform** that takes the heavy lifting out of running a business online. Whether you're a solo entrepreneur, a startup, or a growing brand — BizFlow generates your entire digital presence and hands you the tools to manage and scale it, all from one dashboard.

No tech skills needed. No agency fees. Just AI that works *for* you.

```

📊 Download a Business Growth PDF         →   your custom roadmap
```

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/bizflow-ai.git
cd bizflow-ai

# 2. Install dependencies
composer install
npm install && npm run build

# 3. Set up environment
cp .env.example .env
php artisan key:generate

# 4. Configure your .env
# → Set DB_DATABASE, DB_USERNAME, DB_PASSWORD
# → Set OPENAI_API_KEY
# → Set STRIPE_KEY, STRIPE_SECRET

# 5. Run migrations & seeders
php artisan migrate --seed

# 6. Start the server
php artisan serve
```

> 🌐 Visit `http://localhost:8000` and you're live!
